## State and numerical policy

Pure `src/core/pleiadesAnalysis.ts` creates points only from explicit same-target B and V reading IDs with confirmed manual notebook entries. It recomputes B−V from those entries rather than using acquired/cached colors. One chosen pair per eligible target is presented in original hotlist order; all eight unavailable positions remain unavailable. Original axes are fixed; off-axis points stay in the accessible table and are counted rather than silently clipped without explanation. Orange squares are the14 standards. Dashed straight display segments only aid manual visual alignment; no interpolation/optimizer determines a modulus, stellar value, age or physical curve.

The pupil enters a vertical shift, previews the overlay and calculation, and presses **Confirm manual cluster fit**. New web guards require at least two explicitly paired targets, no running integration, modulus−25..40 at0.1mag steps, and the existing event/byte budgets. These guards are not recovered CLEA limits. The preview starts blank and is never treated as a confirmed fit. Discard returns to the last confirmation or blank. **Full investigation saves preserve unapplied text**, including explicit blank/invalid text, in the separate editing-v2 owner. Raw photometer JSON only saves the scientific/observing journal; raw restore and explicit new-session reset the editing draft. 4. Scroll to **Pleiades color–magnitude analysis**. Inspect **manual plot values** and **printed standards**.
