# Sampled intensity of loaded comparison spectra

The classification readout now admits the unknown from the supported replay-verified stellar acquisition and from eligible imported SP/SSP/CSV curves, alongside the original references and practices. The student explicitly chooses a source and types a wavelength. The result is relative intensity of the retained normalized curve; no continuum, classification, equivalent width, redshift, distance or photon realization is inferred. Existing manual work and session schemas remain unchanged.

## Evidence and policy

The numerical sampler has no origin-specific formula. The native file reader `0x55ee14–0x55f09e` reads the optional SSP header and constructs a uniform first/last/lastIndex grid, discarding interior wavelength tokens while retaining intensities. This supports a bounded loaded-curve adapter; it does not prove the original live-acquisition handoff or native file-dialog/event behavior. It is not sampled from the original noiseless template or directly from integer count bins. The existing acquired-star bridge already normalizes source-plus-sky counts with the recovered positive maximum and formats wavelength to two/intensity to six decimals before linking that file derivative to its replayed journal. No extra normalization, clipping, smoothing, continuum matching, sky subtraction or new counts are introduced here.

The native reader does not validate interior coordinates. This port adds a deliberately narrower admission gate: at least three rows, the comparator's existing finite increasing 0–1 input/3900–4500Å coverage rules, and every printed coordinate within both 0.01Å and1%of one channel of the endpoint-reconstructed line (plus absolute1e-9Å Number allowance). Independent rounding of true uniform endpoints/interior values to two decimals contributes at most0.005+0.005=0.01Å deviation. That derivation motivates the absolute guard. A separate conservative1%channel cap rejects fine-grid coordinates displaced by most of one channel; it is an additional support limit, not a recovered physical error bound. Both guards are new browser policy, not recovered native validation or proof that arbitrary input was uniformly measured. A two-row or more irregular file stays available for visual comparison and existing manual responses, with an explicit numerical-unavailable message. The guard does not modify, resample or repair its plotted rows. CSV support remains the existing browser parser adaptation.

Within the admitted profile, the readout reconstructs the endpoint grid explicitly, even where rounded interior coordinates differ slightly. Original plots continue using printed coordinates. A saved default stellar file ends at4698.33Å; the reconstructed step is99833/59900Å, rather than the pre-format5/3Å channel step. Choosing a policy by these actual bytes avoids silently sampling a different raw grid. Numerical interpolation can legitimately overshoot below0 or above1; the returned finite value is not clipped. Number arithmetic, textual display and bounded errors are declared adaptations, not x87/native-runtime equivalence.

## Identity and lifecycle

Imported identity is `imported:<actual byte SHA-256>` and never gains acquired/library origin from a filename, marker, catalog-looking label or byte equality with a reference. Acquisition identity is `acquired:<replayed acquisition ID>`, with a separate derivative-file SHA-256; both are retained in the result. Source kind is visible beside the reading; method details show its file SHA and acquired ID when present. The pure adapter requires trusted IO inputs: import/reimport/restore hash and reparse bytes; acquired snapshots are rebuilt by replaying the journal. The adapter does not itself attest cryptographic origin.

The comparison component checks the actual displayed sample-array/hash association before preparation. Changing unknown, atlas, pair or readout source clears the old result. Replacing the retained external source during same-page restoration immediately invalidates the old curves, reloads from the new trusted object and clears the old readout, even when source ID/hash/atlas/pair match. Invalid wavelength input produces a linked error. Enter reads from the input; a persistent live region exposes results. Save preserves the current temporary readout and scientific session bytes. Full restore revalidates imported bytes and acquisitions; the readout is not serialized. Equivalent width remains available only in its earlier admitted original-practice domain. Difference mode retains its exact printed-grid restriction. These independent gates are not relaxed by sampled intensity.

## Try the feature

1. Open http://127.0.0.1:5173/#star-exposure. **Activate supported star field**, **Start star exposure**, accumulate a positive exposure, then **Classify acquired star**.
2. In **Read spectral intensity**, keep **Unknown** selected in **Spectrum to inspect**, type `4101.74` in **Read wavelength (Å)** and press Enter. The result says **Acquired stellar snapshot**. Expand **Sampling method and source** for the derivative SHA and acquisition identity. The number depends on your counts/seed/time; no fixed scientific answer is supplied.
3. Use **Measure this acquired star**, **Download acquired SSP**, then **Stellar classification** and **Import spectrum for comparison** to load that saved file. Read the same wavelength: expect the same displayed intensity, labelled **Imported file**, with the SSP's own byte hash. Its header does not grant acquired provenance. Save/reload/restore the complete investigation to retain raw journals and manual work; the temporary reading must be entered again.
4. For a small explicitly synthetic input, import a text file containing `3900 0`, `4200 1`, `4500 1` on separate lines. Read `4350`: expect `1.125`, demonstrating unclipped interpolation. This is a test curve, not an observation. Your manual response remains blank until you enter one.
5. Import `3900 0`, `4000 .5`, `4500 1` on separate lines. Visual comparison remains available; numerical sampling explains the grid gate. Select **Upper standard** explicitly to inspect that reference instead. No imported width or automatic class is enabled.
