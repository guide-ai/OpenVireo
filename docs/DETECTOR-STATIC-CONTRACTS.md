## Original resource and public GDI semantics

M82.BMP is a376×205,8bpp,uncompressed bottom-up image,216 palette entries and376-byte stride. Palette entries are descending gray215..0: an index is not its intensity. The original file has78000bytes andSHA256`d7546c01ee84e788bbecdf15dc3f73568a5427143ccef488063536c48c7bc23a`. Direct header/palette expansion and an independent existingImageMagick decoder agree for everyRGB byte (decodedSHA256`d66430fd8aa5b4567a8ba816cbad528cbbb354548518c7fc280bea16dbf65229`). GLIMAGES.LST supplies376,205 and hotspot188,103. The0x597470 draw subtracts signed hotspot coordinates from rounded projectedDouble x/y; it does not establish a calibrated detector frame by itself. Source image astrometry/magnitude differs from the galaxy catalog and does not replace it.

Microsoft's [BITMAPINFOHEADER](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/ns-wingdi-bitmapinfoheader) and [RGBQUAD](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/ns-wingdi-rgbquad) specify palette lookup, B/G/R byte layout, orientation and DWORD row alignment. Those resource-decoding questions are resolvable statically; they are not a reason to require Windows.

[StretchBlt](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-stretchblt) uses source/destination rectangles and current stretch mode; [SetStretchBltMode](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-setstretchbltmode) distinguishes pixel deletion(COLORONCOLOR3) from approximate block-color mapping(HALFTONE4). These pages do not specify the exact eliminated-pixel phase or HALFTONE numeric kernel. The native VCL bitmap path0x431714 selects a mode using device/source depth and realizes palettes. Implementing browser bilinear or an assumed nearest-neighbor phase would add a numerical choice. [GetPixel](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-getpixel) returnsCLR_INVALID outside the clipping region; its red byte255 means no byte-valued star can replace an off-frame destination. This supports the painter's bounded clipping rule, not inventing black pixels for missing source reads.
