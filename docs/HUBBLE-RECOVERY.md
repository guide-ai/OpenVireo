# Hubble acquisition recovery

The observatory is usable at `http://127.0.0.1:5173/`. This increment adds pure numerical, calibration and exposure-state building blocks in `src/core/acquisition.ts`, `photons.ts`, `exposure.ts`, `galaxySpectrum.ts`, `galaxyRaster.ts` and `galaxyContinuum.ts`; it does **not** expose an acquisition control or manufacture an observed spectrum. The source remains VIREO `CLEA_VEO.exe`, SHA-256 `781bc9704b4674038267834a9ed21d502c455378d8fc9eb15a1653e20c52c54c`.

## Recovered and implemented contracts

The metadata in `data/hubble/PROVENANCE.json` identifies the original assembly ranges, REA evidence IDs and raw constant bytes. Research dossiers remain outside this web project. Ghidra pseudocode alone was insufficient: x87 arguments, stack ordering and Delphi constructor branches required assembly inspection. No original executable or microemulator was run.

Ranges above are inclusive byte addresses, including all bytes of each instruction. A RET instruction address and the end of its encoded bytes can differ.

`0x403700` performs FISTP under the current x87 control word. Sampling uses an explicit nearest-even browser policy; original session rounding has not been established. `0x40370c` temporarily sets truncation mode; nonnegative Poisson candidates therefore use `Math.trunc`. Original Extended values, transcendentals and threshold decisions can differ from Number/Math, and therefore can change subsequent random draws. No bitwise noise or original-spectrum equivalence is claimed.

The original Poisson cache stores prior mean, sqrt(2 × mean), log(mean) and its normalizer/exp(−mean) as 10-byte Extended values at offsets 0, 0xa, 0x14 and 0x1e, and compares Extended means with FCOMPP. It is initialized with prior mean −1 (`0x55f0d0`). The browser recomputes parameters for each Number input; identical Number inputs give identical deterministic parameters. This does not establish equivalence with original Extended caller values. The original spectrometer constructor supplies seed zero to that initializer, which invokes `0x4035a0` to obtain a session seed; a zero value in the executable's data section is **not** the original session seed. Browser callers must supply a uint32 seed. The module does not call Math.random, clock APIs or any platform RNG.

The rejection branch consumes an acceptance uniform even when exponent <−30 produces a zero threshold (`0x55f2b3→0x55f2d7→0x55f2f3`). Negative candidates jump directly back to the angle draw without consuming an acceptance uniform (`0x55f265`). Independent synthetic vectors now pin both sequences and a normal acceptance using integer LCG arithmetic and exact factorial ratios, independently of the recovered gamma implementation.

One representational boundary remains unresolved: uniform exactly 0.5 places the tangent at a pole. The original Extended pi is slightly above mathematical pi, while binary64 Math.PI is below; original x87 argument-reduction behavior has not been measured. The adapter now reports a typed `precision` error at this exact draw. It does not silently substitute a random branch or claim that the original would throw. Seed 2796574515 reaches that boundary in one draw. A future integrated exposure must surface this limitation atomically; full original numerical fidelity remains gated on stronger evidence. Exact decimal representations of Extended constants are retained alongside their binary64 projections in the provenance.

New protection policies are explicit: nonnegative finite mean <=1,000,000; draw budget 1–100,000 (default 10,000); unsafe integer candidates, nonfinite arithmetic or exhausted budgets throw a typed error. These are adapter limits, not recovered detector saturation, timing or physical calibration. A rejected call cannot mutate its input state. Callers must keep returned RNG state and count together when integrating later.

## Slit and magnitude calibration building blocks

`src/core/photons.ts` implements the supplied-image arithmetic, without claiming that the supplied image is an original detector frame:

- `slitPixelLevel`: read 57 RGB pixels in a centered 3×19 rectangle, sum all three channels, divide by **57**, then round. This produces a level from 0 to 765; dividing by 171 or normalizing RGB first would change the recovered contract. New guards require a complete rectangle, matching RGB byte length and at most four million pixels. No out-of-bounds Windows GetPixel behavior is reproduced.
- `galaxySlitFraction`: level >=200 gives 1; otherwise `(level / 200)^2`. This is the galaxy branch at `0x50f42c–0x50f45a`; it is not a generic Gaussian slit model.
- `telescopeZeroPoint`: `0x53df4f–0x53df5e` reads the general Single calibration and telescope Single correction, adds them, and stores Single at telescope+0x6f0. The adapter uses Math.fround for those boundaries.
- `magnitudeAmplitude`: the reset routine `0x50df64` uses `10^((magnitude − zeroPoint) / −2.5)`. `photonAmplitudes` keeps source and sky distinct, applies supplied source throughput and supports explicit sky-only input. These are amplitudes before spectral sampling and elapsed multiplier, with no unverified count/time unit attached. A galaxy's source magnitude must already include its recovered correction; the helper does not substitute apparent catalog magnitude for that value.

Compiled fallback defaults are now traced from `0x5a21d0`: base zero point **6**, sky magnitude **19**, spectral interval **3700–4700 Å**, elapsed multiplier **50**, spectrometer timer interval **1 ms**. These are **fallback settings**, not observations of an original session: `0x5a3534` first reads a binary options file named VEO_OPTS.INI. The general record begins at environment+0x6b4; its offsets are preserved in the provenance. Default telescope corrections at `0x5a3174` are −2, 0 and 3, yielding stored zero points 4, 6 and 9. No new telescope selector or exposure control is exposed from these values.

Original image composition is a concrete native-GDI oracle gate; see [the exact pending experiment](HUBBLE-ORACLE-PROPOSAL.md). The canvas is populated from a larger rendered sky bitmap and can use original galaxy images or generated shapes before cropping and overlays. Sampling the displayed reference PNG alone would bypass that pipeline. The axis-ratio and position-angle helpers were identified by their assembly, including deterministic fractional-part fallbacks; their analyst labels are not source-level symbols.

## Exposure state with supplied means

`src/core/exposure.ts` implements a pure 600-bin reducer, with per-bin source means (or explicit sky-only mode), one uniform sky mean, elapsed multiplier and seed supplied by its caller. Original source preparation has not been replaced by those synthetic test inputs.

- `createExposure` and `resetExposure` clear counts; reset retains the current RNG seed. Start/pause/resume preserve counters and supplied source means. A distinct source array of zero means still consumes source draws; sky-only mode skips them. Every zero-mean Poisson call still consumes one uniform.
- `advanceExposure(deltaMs)` uses signed low32 IMUL for multiplier×deltaMs, then draws source followed by sky for each of the 600 bins. It accumulates counts, source/sky totals, elapsed milliseconds and draw count. The timer's display scale is 200/max(1, counts); its legacy S/N is sqrt(total counts/600), not a newly introduced signal/background estimator. Above 1000 it pauses with a limit reason.
- Explicit delta milliseconds replace GetTickCount and VCL event delivery; this reducer does not infer elapsed time from browser animation frames. Its accumulated elapsed time is a safe Number integer, not an emulation of original tick-counter wrap. Delta admits uint32; unsupported negative wrapped means are rejected by the noise-domain guard.
- Original bin and sky-total storage is signed int32, source and combined totals use int64 with FILD/FISTP. Browser state rejects int32 count overflow and unsafe Number totals instead of reproducing negative wrapped counts, x87 invalid conversion or memory corruption. This is a new protection policy. Restarting after the legacy S/N limit requires reset in this adapter.
- A complete tick is committed only after all draws and count checks succeed. A precision/domain/budget failure returns no partial observation and leaves input state unchanged. Callers must preserve that transactional behavior when connecting presentation and save operations.

Independent BigInt vectors pin exact seed consumption for a nonzero first source bin, zero-valued source/sky bins, sky-only mode, pause/resume and low32 multiplication wrap. A test also reaches the exact tangent midpoint and verifies that no partial counts or seed escape. These are bounded synthetic contract checks, not original exposure observations.

## Bounded galaxy spectrum and raster tables

`galaxySpectrum.ts` prepares 600 values from an explicitly selected SP or fallback; it does not select an object, change the telescope or expose Go. Matched library spectra use wavelength factor1. A fallback uses1+catalog redshift stored as Single. The original constructor ignores interior wavelength tokens and assumes a uniform endpoint grid; the adapter instead verifies a dense uniform grid with tolerance1e-7 of the sample step,3–50,000 finite samples and a positive minimum. It rejects a nonfinite interpolated result (including overflow from finite inputs), a negative interpolated source, nonfinite/z<=−1 in both matched and fallback branches (a new catalog-domain restriction even though matched in-SP wavelengths ignore z), a configured range wider than100,000Å, and an out-of-SP channel. Those are new explicit guards, not original error behavior. No arbitrary flux normalization, resampling kernel or randomized continuation is inserted. Lower-level grid/interpolation failures are translated to GalaxySpectrumError; nonfinite shifted endpoints report overflow before grid construction. Tests check both error class and code.

The calibration reads configuration Single min/max, truncates min/100 toward zero, advances the rounded maximum only while it is lower than the configured maximum, retaining an already aligned100Å boundary and divides the resulting span by600. Go begins at the actual configured minimum. The adapter supports positive ranges; for an unaligned interval such as3720–4680Å it deliberately gives3720..4718⅓Å, preserving this distinction. The returned arrays are immutable. Original Extended arithmetic can disagree with the Number calculations. The original comparison loop is0x50ed14..0x50ed65; step is stored as10-byte Extended at0x50ed88, not Single. Go0x50f4f4..0x50f51c multiplies index by that step, adds the configured Single minimum and stores an Extended argument; it does not accumulate successive steps. Its galaxy branch multiplies sampler output by the prepared Extended amplitude at0x50f546..0x50f55d, with no additional bin-width factor on that path.

Each required original fixture is resolved relative to the test module and checked against its SHA-256 before parsing; a missing artifact fails explicitly and is not silently skipped. Independent Python Fraction/Lagrange vectors check M82 and Coma2's original SP files on the default range and Coma1's fallback on an explicitly different3800–4700Å test range. That changed range is a test scenario, not a replacement default. Coma1 at the actual default is separately tested to fail with `extension-required` because its shifted template starts at3737.368Å. The original FPU control word and full Extended operation results remain unmeasured; the fixed Number policy is not an original-run oracle.
