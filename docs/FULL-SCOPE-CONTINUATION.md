These are supported slices,not full original instrument/exercise or runtime equivalence. Historical earlier docs may describe a smaller delivered subset.

## Still implementable through further recovery

General optical field/cache/calibration associations,instructor options and timing/display branches;further exact native image representations and original CCD/IR camera preparation/display/output contracts;radio antenna/receiver/pulsar sampling;multi-object/fiber association;wedge/orbit/image analysis and the remaining historical/associated laboratories. These are unimplemented or have unrecovered contracts,not all permanently blocked. Existing VIREO code/forms and shipped resources can support further static recovery;each scientific path still needs complete source ownership,units/precision/error contracts and independent controls before product admission. Loading another generic file is not a substitute for those observation/analysis workflows.

The first image increment does not implement a new CCD photon model. Next high-impact image work is recovery of a complete native camera preparation/display route and its pixel/metadata owners,then an evidence-backed observing or analysis action. The recovered VIREO FITS unit is a writer;the new supplied-image browser reader must not be described as a demonstrated native loader UI. The bundled toolkit.exe is an InstallShield installer,not an already inspected astrometry scientific executable;it was only read/hashed,never run or installed. Other-edition payload/format availability must be verified before promising their workflows.
