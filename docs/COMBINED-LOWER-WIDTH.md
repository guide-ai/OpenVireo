# Combined bottom width-source selection

The existing **Select width source from the center pane** option now supports the combined bottom pane. Committing a center there selects the admitted **lower standard** for equivalent width, while the pane continues to display the **unknown** trace. A notice names both identities before and after selection. Inspect reads the displayed unknown; width calculation uses the selected standard's actual retained spectrum. This closes the previously withheld categorical combined-source route, not full classification acceptance.

## Try locally

1. Open `http://127.0.0.1:5173/#classification`. Choose **Spectrum rendering → Combined photo and trace**. Leave the first atlas/pair selected for this example.
2. Under **Manual equivalent width → Comparison pane marking**, check **Select width source from the center pane**, then click **Mark comparison center**. The bottom trace now explains that automatic width selection will use the lower standard. A held preview or Escape does not select it.
3. Press/release on the bottom trace near4150Å. **Equivalent-width source** becomes **Lower standard · B0 V**. Its selected source is `standard:main:s2`; the visible bottom trace remains unknown `practice:u1`. The cross/shoulders belong only to that bottom representation, not the unknown photograph above it.
4. Choose **Mark comparison shoulder**. Press/release one point near4100Å and another near4200Å, at different positive manual heights below1. On desktop, right-clicking with center mode selected also marks a shoulder. All coordinates and continuum heights remain your own selections. You may enter exact values in the five fields, but numeric edits end the shared-pane origin.
5. Expand **Mark a feature on the curve** below to inspect the actual lower-standard curve. Click **Calculate equivalent width**. The result identifies **Lower standard** and **Original reference**. **Close width result** leaves confirmed practice records untouched; standard calculations are temporary. Changing back to **Trace** with the same numeric inputs gives the same calculation, because source choice does not depend on displayed flux.
6. Return **Equivalent-width source → Unknown** to recover its existing practice draft/records. To mark the unknown in the bottom trace explicitly, uncheck automatic selection first. The checkbox affects center commits only; bound lower shoulders remain editable in their original bottom pane after it is unchecked.
7. On mobile, focus the bottom marking surface: an arrow previews movement and Enter/Space commits. Use the shoulder tool for touch. Scroll the desired pane into view before marking; Escape, release outside, source/atlas/rendering changes and held transform changes cancel stale gestures.
8. With a complete bound region, zoom in and pan until an endpoint leaves the window: both shoulder indicators hide, numeric fields remain, and Calculate pauses with the existing explanation. Reset redraws them. Changing the region or view during result review closes that review; an old confirmation cannot save it.
9. Save **complete investigation**, reload and restore it. The established format retains practice/raw acquisition/import/record data; temporary reference inputs, automatic option and pane geometry are not restored. Rendering returns to **Trace**. Choose combined and enable marking again to start another temporary lower-standard measurement. Invalid SP/SSP import preserves current work and exact imported bytes.
