Current editing follow-up: [conditional shoulders and held geometry](CONDITIONAL-SHOULDERS.md) adds ordered revalidation and native left-center/right-shoulder mouse action within this separate source-bound tool. It does not change the numerical or persistence boundary below.

The existing **Manual equivalent width** tool now completes the source-selection → manual center/shoulders → calculation → result flow for the actual **Unknown**, **Upper standard** or **Lower standard**. Admitted unknowns include original practices, verified visual imports and the supported acquired-star derivative. It reuses the existing cursor, manual fields and recovered integrator. It adds no continuum fit, display normalization, source spectrum, class answer or grade.

Original-practice unknowns retain their existing saved draft/confirmed input/recompute flow. For references and imported/acquired unknowns, inputs/results are explicitly **temporary**. **Close width result** keeps a source-labelled result on screen; changing source, inputs or workspace invalidates it. Nothing is added to JSON/CSV or a native observational-results archive. The observed native calculation handler displays results without writing an archive in that handler; this does not prove that other native file APIs are absent. No user format/version is changed to implement this bounded calculation branch.

## Original source resolver and numerical policy

[Provenance](SELECTED-SOURCE-WIDTH-PROVENANCE.json) re-verifies11 existing byte/listing captures against `CLEA_VEO.exe` SHA-256 `781bc9704b4674038267834a9ed21d502c455378d8fc9eb15a1653e20c52c54c`. It retains resource bindings, original help/manual/license hashes and source-specific uncertainty. No original execution or additional original resource is involved.

Evidence `VIREO-EW-ST-02`, `0x50670f..0x506819`, resolves the spectrum from the marked panel: unknown pointer`+4bf`, the selected upper atlas row or its following lower row. Unresolved source selection rejects. `0x506851..0x5068b5` passes that pointer and manually selected shoulder wavelengths/intensities to constructor`0x55f6a4`. Its callback`0x55f744` evaluates `1 − F(lambda)/C(lambda)` with the same source. `0x506936..0x50696b` samples that source at the manual center; `0x50699e` integrates; `0x506a26..0x506a3a` shows the result, clears the measurement flag and hides the instruction control. Cleanup and literal pools are separate from numerical behavior.

`selectedFeatureSource` checks the actual prepared probe, source role/kind/ID/hash, retained flux-array/grid association, private probe admission and coverage. Original references cannot be relabelled as practice unknowns, nor loaded unknowns as standards. Imported files with identical original bytes still retain imported authority. IO owns actual cryptographic byte verification, parsing and acquisition-journal replay; a claimed digest alone is not proof of origin. Two-row or irregular visual imports retain comparison support but are rejected for this width path, rather than borrowing reference admission or silently choosing another interpolator.

The calculation calls the unchanged `measureFeature` core: linear manually chosen continuum, original endpoint-grid quadratic sampler, refined trapezoids/Richardson extrapolation, strict relative`1e-4` stopping test and20-refinement ceiling under `VIREO-EW-Number-v1`. It still requires `3900 <= left < center < right <= 4500Å` and manual continuum levels in`(0,1]`. Broader display ranges, visible maxima, grayscale/reverse and normalized difference never set the region or rescale this source. Acquisition source-plus-sky counts remain added; this tool does not subtract sky or establish a physical stellar class.

Raw zero-source flux is permitted on an admitted grid: a display photo can lack a positive peak while the manual integral is still defined. An exactly zero residual instead exhausts strict relative convergence; the value is visibly provisional. A temporary provisional result can be inspected but cannot become a saved width record. No absolute tolerance, smoothing, replacement integration or physical uncertainty is invented.

Passing the recovered stopping test is not an absolute integration-error guarantee. The [independent validation](SELECTED-SOURCE-WIDTH-VALIDATION.md) records a converged Number case differing by0.1295181113Å from a high-precision piecewise analytic reference. That is a measured operator-fixture difference, not a general error bound, uncertainty estimate or original-runtime oracle.

## Isolation and continuity

The selected role plus actual source ID/hash and unknown workspace identify temporary inputs/results. Switching upper/lower/unknown or changing that source identity clears temporary work; reload or leaving the workspace also clears it. Atlas changes revalidate the actual source: reference identities change with the atlas, while an unchanged unknown remains its own source. Loading/restoration cancels pending calculation dialogs, and no stale result is relabelled. Manual fields or cursor marks invalidate the displayed result. A temporary reference draft cannot overwrite a practice draft or record. Source hashes/types accompany both result review and retained readout. Reload/restore does not invent non-practice input fields from a session.

Legacy practice input records remain subject to their existing source inventory, version,20-record bound, explicit confirmation and recomputation. Switching back to the original-practice unknown restores that practice's saved draft. **Save width measurement** remains practice-only and requires convergence. Classification CSV remains classification-only. The Hubble analyser and acquired counts/seeds/journals remain unchanged.

## Try the complete flow

1. Open `http://127.0.0.1:5173/#classification`. Enter your own proposed class/reason or partial practice width draft and save the complete investigation for comparison.
2. In **Manual equivalent width**, select **Upper standard** under **Equivalent-width source**. Its label identifies the actual reference. Expand **Mark a feature on the curve**, mark a center, then left/right continuum shoulders; typed fields remain available.
3. For a workflow trial only, enter center4150, left4100, right4200 and both continuum levels0.99. These are operator-selected test inputs, not prescribed feature boundaries or an astronomical answer.
4. Click **Calculate equivalent width**. Verify the source kind/hash and manually chosen region. **Cancel width measurement** or Escape keeps the inputs and adds no result/record. Calculate again and **Close width result** to retain the temporary readout.
5. Choose **Lower standard**: the previous result and temporary region clear. Return to **Unknown**: the original practice draft remains. Its existing calculate → **Save width measurement** → JSON/recompute flow is preserved.
6. Import a uniform SP/SSP covering3900–4500, or acquire the supported star and choose **Classify acquired star**. Select Unknown, enter a manual region and calculate; the result identifies the imported/acquired source and stays temporary. An uploaded original reference can match its reference width without gaining original authority.
7. Try an irregular/two-row visual import: width calculation stays disabled while visual comparison and independently selected references remain available. Malformed import/cancel preserves existing scientific work. A flat synthetic unit-flux test with continuum1 demonstrates provisional zero-residual nonconvergence; it is a validation fixture, not an observation.
8. Save the complete investigation before/after temporary work: bytes stay identical. Reload/restore returns acquired journals, exact imported bytes, manual classification and original-practice width records; temporary non-practice regions/results are absent. Inspect the same controls/result dialog on mobile or with keyboard navigation.
