# P01 acceptance — English UI/help and translation-ready catalogs

**Decision: accepted complete against all original P01 criteria for the current authored application.** This assessment uses the original P01 acceptance text, without changing its scope: **“All authored user text keyed, interpolation tested, locale/scientific formatting separated; later locales remain optional.”** See `IMPLEMENTATION-PLAN.md`, functional row P01, product language policy and web-presentation architecture. P01 concerns the currently authored product UI/help; historical source material, observations and scientific file formats are data. It is not acceptance of any scientific laboratory, native runtime fidelity, educator review or public release.

New desktop browser coverage exercises metadata, plot title/description, generated Hubble notices/issues, exact pre-change Chromium CSV hashes, explicit target claims, literal Unicode/brace/HTML-looking operator text and save/reload/restore. Mobile coverage exercises typed decimal-line errors, a UTF8 runtime failure through catalogued fallback, retention of the current file/manual observation and320px layout. Existing67 flows cover the wider observatory, acquisition, Hubble, classification, photometry, import/cancel/reimport and restoration paths.

The Hubble SVG had its description referenced as part of its label. The coverage check exposed this pre-existing association error; it now uses `aria-labelledby` for the title and `aria-describedby` for the existing description. There is no visual chart change. Unknown foreign runtime errors now receive an authored operation-specific fallback instead of leaking uncatalogued engine prose; known diagnostic details remain intact.
