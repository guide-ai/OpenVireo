## Endpoint ownership and expression

Both preparation callers test the first projected record's kind byte+`0x3d`. Kind2 consumes the **next list record** through `0x492634`, then supplies both records' Double positions+`0x47/+0x4f` to `0x524a6c..0x525095`. The first record supplies magnitude; the second record is consumed as an endpoint, rather than synthesized or treated as another independent point source. Complete iterator reset/advance/tail procedures are captured. This establishes the caller's pairing order; it does not yet establish the full catalog producer's association, error handling for malformed pairs, or a safe generic catalog-import adapter. The port therefore requires both endpoints explicitly and does not generate them or admit arbitrary projected lists.

With axes `sigmaX/Y`, normalized endpoint separation is `d=sqrt(dx²+dy²)`. The original computes `scale=sqrt(sqrt(d+1))` and duration divided by base-duration times this scale. The numerical API takes the explicit duration/base-duration ratio, then divides by scale. CCD calibration ownership remains shared with the IR caller; no automatic live configuration mapping is added.

The integer support starts3 and grows while `exp(−r²/2)*referencePeak>1`, independently of duration. The rounded midpoint is first endpoint plus half the difference. Each radius is rounded from absolute half-difference plus support times its axis scale. Row-major visits cover that rectangle clipped to the plane. The Gaussian exponent is squared distance to the finite segment in scaled coordinates: the captured expression uses endpoint distances `A/B` and `t=(d²+B−A)/(2d)`; branches choose B, A or `B−t²`. The port preserves those subtractions and finite cancellation effects, without an invented nonnegative repair or flux normalization.

The cross pass runs **only when scale<1.25**. Equality suppresses it completely. Otherwise it retains the original thin-cross ratio overwrite, positive-ratio test and coefficient containing the scaled duration twice, as in point addition. Every visit consumes one supplied uniform and stores Single after adding the shared recovered jitter. Zero peak/time visits still consume their draws. Initial histogram ownership remains unchanged.
