## Try on the persistent local preview

1. Open `http://127.0.0.1:5173/#classification`. Choose **Spectrum rendering** first. Under **Manual equivalent width**, choose **Equivalent-width source**, then **Mark comparison center** in **Comparison pane marking**. Only that displayed source edits; other panes still inspect. A lower standard has no pane in combined mode.
2. Press/release inside its comparison pane to mark a center wavelength. With center mode selected, use the right mouse button for one shoulder on each side. Alternatively choose **Mark comparison shoulder** and use primary click, touch or keyboard. Only shoulder heights set the manual continuum. Nothing fits a continuum or supplies a classification answer.
3. As a workflow fixture, manually try center4150Å and shoulders4100/4200Å at0.99. Calculate, inspect the source/result and **Cancel width measurement**; calculate again to save a converged original-practice input record. Other admitted sources use **Close width result** and keep temporary width work. These trial inputs are not recommended astronomical boundaries.
4. Zoom while editing. A valid center with a known panel origin takes priority as the zoom anchor; the existing interior-column/range policy still applies. Pan/reset or layout changes cancel a held preview but retain committed inputs and panel origin. Wider display ranges do not admit width marks outside3900–4500Å.
5. In **Combined photo and trace**, mark the center on the unknown photo and try a shoulder on the unknown trace: the tool rejects it without changing input. A new center in the trace explicitly starts a fresh bracket. Within the same panel, moving the center retains the existing ordered right-then-left revalidation.
6. Numeric or separate-manual-tool edits remove the shared panel origin. A new shared center is required before further shared shoulders and starts a fresh draft bracket. This never removes confirmed records. Source/rendering/activity changes end shared editing; reload/restoration restores only the established numeric input/record formats, with inspection selected and no origin. Restored numeric regions can still be calculated or recomputed without entering shared editing.

8. Import a valid SP/SSP or classify the supported acquired star and repeat. The actual admitted source identity stays authoritative. Invalid/cancelled imports retain existing work; same-byte reimport remains imported.
