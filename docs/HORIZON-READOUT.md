## Why drifted spectral photons remain unavailable

The old stop rule is retained with an explicit scope label. Static evidence does not establish that toggling native tracking stopped an active native spectrum. Native spectrometer FormShow`0x50d8b8` disables DriveBtn+`0x400`; the native toggle body`0x538768..0x5387e6` calls observatory control helpers, not a corresponding photon-stop routine. The browser permits an additional shared toggle and safely releases integration before its verified fixed-pointing contract is lost. This is a new browser adaptation.

Continuous field drift itself is already recovered analytically (`0x53cb6c` + projection/inverse gives RA0+24h·elapsedDays); it is visible in the actual sky/clock. The separate slit helper`0x50f338` applies strict raw coordinate cuts and a positive actual sampled pixel for stellar types, or the actual galaxy level/200 squared capped at1. It cannot be replaced with an invented smooth transmission curve. A drift path needs repainted detector pixels, correct nearest-object arbitration and native refresh/lifecycle scheduling together.

Specifically, published **FormActivate** selection`0x50dac4..0x50dbd2` computes a slit fraction and source/sky mode, Go`0x50f484..0x50f617` prepares600 cached source means, and timer`0x50f76c..0x50fa92` consumes those means and adds sky draws. The timer does not call the slit routine on every interval. **Correction from the subsequent drift-chain audit:** `0x5110b0..0x5110ea` shows a reinitialization path through FormShow, FormActivate, source setup and FormPaint; it does not call Go (`0x50f484`); its complete event/caller ordering during motion and preserved/discarded buffer behavior is not yet admitted. Multiplying a live offset fraction into every photon interval would therefore introduce an unproved model. No such change was made. Existing source+sky **ADD**, seeds, manual measurements and scientific journals are untouched.

Manual native movement uses a separate20ms form timer and rate/optical-scale state. Original NESW press/release bodies, pole reflection and candidate horizon calls are retained as evidence, not advertised as a continuous motor implementation. Those contracts and native global VCL ordering remain the next dependencies before broadening movement/acquisition controls.
