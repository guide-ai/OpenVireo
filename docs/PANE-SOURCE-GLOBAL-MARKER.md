## Try locally

1. Open `http://127.0.0.1:5173/#classification`. Choose **Spectrum rendering → Grayscale photo**. Under **Manual equivalent width**, check **Select width source from the center pane**, then **Mark comparison center**.
2. Press/release inside the upper photograph. **Equivalent-width source** becomes the upper standard. The center wavelength appears in its input; the vertical marker crosses all three frames and the short cross belongs to the upper frame. A held preview, Escape or release outside the frame does not change the selected source. Press/release in the lower photograph to choose the lower standard.
3. With center mode selected, right-click one shoulder on each side in that same pane. Alternatively choose **Mark comparison shoulder** and use primary click/touch. The ordinate sets manual continuum height; the center's ordinate only positions its cross. Calculate and **Cancel width measurement**. References remain temporary and never append practice records.
4. Return to the unknown using the selector: an existing practice draft and its confirmed records remain. To select the unknown by pane, enter center mode and commit a center there; this explicitly starts a fresh draft bracket. Moving the center within its existing pane keeps the established ordered right-then-left revalidation.
5. Choose **Inspect comparison panes**: the committed global marker remains. Zoom/pan projects the same wavelength into each actual visible window; an outside-window mark hides. A numeric or separate-tool edit removes the shared origin/global marker. Source, rendering or disabled file activity also ends shared editing. Save/reload/restore retains established inputs and records, with inspection selected, the option unchecked and no restored pane geometry.
6. **Combined photo and trace** automatically selects the upper/unknown photographs. Its bottom repeated-unknown trace is excluded from automatic switching: choose **Equivalent-width source → Unknown** explicitly before marking that trace. Its origin remains distinct from the unknown photograph; shoulders cannot cross between the two. The primary difference layout receives the global vertical marker but is not an automatic width target; the supplemental fourth difference pane is outside this feature.
7. On mobile, scroll the intended pane into view in Inspect mode before marking. Arrows preview one visible column or0.01manual height; Shift moves ten. Enter/Space commits; Escape cancels. The checkbox applies only to center commits, so shoulder mode never silently changes sources. Imported/acquired sources use their actual existing admission; invalid imports retain work and exact SSP reimport remains imported.
