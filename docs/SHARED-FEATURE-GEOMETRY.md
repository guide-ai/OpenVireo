# Source-bound comparison feature marks

The comparison display now projects the selected equivalent-width source's **manual draft**, including partial center/shoulder marks. Upper/lower references, practice unknowns and admitted imported/acquired unknowns use the actual retained source association. Selecting another width source removes the old overlay from that pane; the draft does not migrate to a different spectrum. In combined mode, the unknown photograph and unknown trace show the same manual values through their own coordinate systems. The lower standard is not displayed in combined mode, so its marks have no pane there.

This is passive geometry after marking on the existing separate manual graph or typing numeric inputs. Comparison-pane gestures continue to inspect intensity; they do not edit the continuum. Direct native shared/photo picking, cross-pane event geometry and full integer marker lifecycle remain open. All classification and continuum choices remain the student's.

[Validation](SHARED-FEATURE-GEOMETRY-VALIDATION.md) and [hashed recovery](SHARED-FEATURE-GEOMETRY-PROVENANCE.json) describe the supported boundary. No integrator, sampler, count/seed, source bytes, record or JSON/CSV format change.

## Try on the persistent local preview

1. Open `http://127.0.0.1:5173/#classification`. In **Equivalent-width source**, select **Upper standard**. Choose **Mark a feature on the curve**, then mark a center and two shoulders, or type values in its numeric fields. The marks now appear on the upper comparison pane. They are not measurements of that curve's automatic peak or brightness.
2. Select **Grayscale photo** in **Spectrum rendering**. The center, shoulder stems/endpoints and connecting manual continuum appear on the corresponding photograph. **Reverse photographic grayscale** changes the photograph, retaining the manual heights.
3. Switch to **Sampled intensity traces**. The same continuum values map to that native125-row scale. Select the unknown width source and **Combined photo and trace**: both unknown representations project its one draft. The displayed peaks do not rescale manual heights.
4. Try manually entered center4150Å, left4100Å at0.75 and right4200Å at0.5. These are workflow fixtures, not recommended astronomical boundaries. Photo shoulder Y values are25/50 within its85-row strip; sampled-trace Y values are50/75 in its125-row panel. Printed traces retain their established normalized SVG axis.
5. Change one continuum level to0.1. That endpoint is below the cropped photographic band rather than clamped onto its edge; numeric input and the separate manual graph remain available. Zoom/pan the comparison: overlays clip to the actual visible window. Reset restores their view without changing numeric values or confirmed records.
6. Calculate and **Cancel width measurement**; calculate/save a converged original-practice result or **Close width result** for temporary sources. Save/reload/restore: practice drafts/records retain their established behavior; reference/imported/acquired width drafts remain temporary. This display adds no persistent fields.
7. At360px, photo/sample panels keep their existing synchronized horizontal scrolling. An actual acquired star and its exported/reimported SSP use distinct acquired/imported identities, with raw counts and exact imported bytes retained. Invalid imports preserve the prior source/overlay; unsupported sources hide width overlays and keep their established fallback/admission message.
