# Pulsar Parameters reference utility (Radio route)

Status: **bounded reference utility**. It ports the TPlsrDataForm1 window (VMT `0x56871c`) and its Find dialog TSearchInput1 (VMT `0x5682f0`) over a catalog the learner loads into memory. It is not a receiver, acquisition, measurement or timing tool. It does not complete Radio I06/I07/N07/E06 and claims no original-runtime or scientific equivalence. Provenance: `RADIO-PULSAR-PARAMETERS-PROVENANCE.json`.

Evidence tags: **[S]** static listing of CLEA_VEO.exe (SHA-256 `781bc970…c54c`) from the dossier `analysis/radio-pulsar-parameters-20261024` (31 manifest files, five addenda) · **[D]** DFM resource text · **[I]** analyst inference · **[W]** web policy. There is no original runtime proof. Excluded and not used: the TRadioLab metadata file, the RA-12 field-role file, the G2 receipt and any field-role claim derived from them, and the historical compiled-Find-mode assertion in `RADIO-ANTENNA-PROVENANCE.json`.

Modules:

- `src/core/radioPulsarParameters.ts`: pure state and numbers (no React, I/O or clock).
- `src/core/radioPulsarReferenceCatalog.ts`: pure web admission adapter (tokens, identity).
- `src/components/RadioPulsarParameters.tsx` (+ `.css`): host hook, window card, Find dialog and box.
- `src/components/RadioTelescopeRoute.tsx`: renders the card after the date card and joins the modality gates.
- Unchanged in behaviour: `radioPulsarCatalog.ts` (codec) and `radioPulsarSelect.ts` (picker). Only their header comments now name this consumer.

## Native contracts [S]

| ID | Routine | Contract used |
|---|---|---|
| PP-05/07 | FormActivate `0x568c4c` | Nil catalog owner: nothing. With a shared name (+0x5f7 non-empty) scan from the head for the first record with `Pos(sharedName, rec.J2000) > 0` (`0x568ceb`, a literal **substring**, not equality); else the head. Local JD := date getter `0x487bcc(env+0x37de)`; density := Extended `{0xf5c28f5c28f5c28f, 0x3ff9}`; display. |
| PP-01 | Display `0x568e10` | J2000 (+0) and B1950 (+0xd) names; RA via `0x486bc0(2)` (whole hours, minutes, `ffFixed 2` seconds); Dec via `0x486bc0(1)` with `IntToStr(sign × degrees)` (a Dec in (−1°, 0°) shows `0`); P fixed 12; PDot exponent (5, 2); PEpoch − Single 2400000 fixed 4; Sky fixed 1; DM fixed 2; W50 fixed 1; S400/S600/S1400 fixed 1. Then both derived routines and Update `SetEnabled(false)`. |
| PP-02 | Period `0x5690c4` | JDEd := `J − 2400000` fixed 8; PrdEd := `P + PDot × ((J − PEpoch) × Single 86400)` fixed 12, in this order. |
| PP-03 | Distance `0x56919c` | DnstyEd := density fixed 3; DistEd := `IntToStr(Round(Single DM / density))`; `Round 0x403700` is `FISTP` under the current control word; no zero/finite guard. |
| PP-04 | Update `0x5694f8` | A non-empty Date text: `StrToFloat + Single 2400000` stored at once. Then, separately, a non-empty Density text. Then both derived routines and `SetEnabled(false)`. No local handler: a Density failure keeps the stored Date, skips the refresh and leaves Update enabled. Empty text keeps the prior value. |
| PP-05 | Reset `0x56960c` | Getter + density literal, both derived routines, `SetEnabled(false)`, `Default(false)`. |
| PP-06 | `JDEdChange 0x5695ec`, `DnstyEdChange 0x569670` | `SetEnabled(true)` and `Default(true)`. Addendum UPDATE-DEFAULT-SETTER: `0x43fb98` is the VCL **Default(Boolean)** setter (RTTI `0x4381f9`, `0x480848`). |
| PP-07 | Next `0x569274`, Prev `0x5692b4` | At the tail/head `MessageBeep(0x30)` (`0x408c44`) and nothing moves (no wrap); otherwise move and display. |
| PP-08 | Find `0x5692f4` | The dialog object is created once and reused. Only ModalResult 1 scans: save the cursor, scan from the head with `Pos(query, mode = 2 ? J2000 : B1950) > 0`. Hit: display. Miss: restore the cursor (no display) and show a box built from literals `0x5694d8`/`0x5694dc` (addendum FIND-MISS-LITERALS: `"` + query + `" Not Found in List!`, button word `0x5694f4` = 4; `0x403c20` appends with destination capacities 13 and 33 (addendum FIND-MESSAGE-APPEND-BOUNDS), so the 12-character query is never truncated). |
| PP-09 | TSearchInput1 | FormCreate: query '' and mode 0. FormActivate: an empty stored query takes the mode from env+0x37ce (0 becomes 1) and the shared B1950 (mode ≠ 2) or J2000 name, **written to the stored query and mode**; a non-empty query and mode are kept; the compiled text `0152-1637` is always overwritten. OK: first 12 characters, no trim/case fold/prefix; mode 2 when J2000 is checked, else 1. Cancel: ModalResult 2 only. `Pos 0x40640c`: raw bytes, empty needle → 0. |
| — | PulsarList1Click `0x567f80` | Picker with Extended 2.0 on +0x5df/+0x5e9; copy the hit to, or clear, the shared +0x5f7; create or reuse the form; `WindowState := wsNormal`; `0x47a010`. |
| — | Exit1Click `0x569234` | Frees the Find dialog (its query/mode are lost), clears `0x5bcc98`, frees +0x460, calls `0x479d50`. |

## Web policies [W]

- **WEB-PP-SRC-01 Local admission.** A browser file chooser; size check (above 1 MiB refused before reading) → `arrayBuffer` → `resourceSha256` → `parsePulsarCatalog` (unchanged codec) → commit. Memory only: nothing is uploaded, bundled, copied or persisted. The original's automatic path, failure box (`0x564d08..`) and conditional quit request are not reproduced.
- **WEB-PP-SRC-02 Identity.** File name (≤ 128 characters, text only), bytes, SHA-256, record count. Equal SHA-256 *and* size to the recorded `Pulsars.dat` (`ba94ee94…ceaa`, 285 692 bytes) is labelled "matches the recorded bytes", which identifies bytes, not runtime authority; anything else is a user-supplied reference catalog. The original file is not one of the 1279 resources.
- **WEB-PP-SRC-03 Lifecycle.** Each read has a token. Cancel button, route hidden, project operation, page hidden and unmount cancel it; every await re-checks token and gates. Invalid, too large, read error, cancel or a late completion keep the previous catalog and identity. Loading is refused while the window is open; Open is refused while a read is pending. Reimport of the same name replaces catalog and identity together.
- **WEB-PP-OPEN-01 Open.** Available once a catalog is admitted and no read is pending. Seed = nearest source within 2.0 (`selectNearestPulsar`) only after the antenna's first activation (no native pointing exists before it). A window is created (fresh Find memory) or reused (Find memory kept), then activation runs. Another catalog object starts a fresh window.
- **WEB-PP-OPEN-02** Activation runs only at Open (G1).
- **WEB-PP-OWN-01 Ownership.** The window owns its frozen catalog reference and one private index (form+0x45c and the list cursor). The seed is a local copy of the two names. Nothing writes the receiver source, the antenna, the clock scenario or a shared buffer.
- **WEB-PP-CLK-01 Clock.** At Open and Reset the local JD is the radio clock scenario's reading (`readRadioClock`, WEB-CLOCK-01) when it is `ok`, else `null`: Date and Period stay empty with a note. No host `Date.now()`, no `0x5bad48`/observatory offset; the read has no side effect on the scenario.
- **WEB-PP-EPOCH-01** 2400000 everywhere. `J − 2400000` is the textbook MJD + 0.5; the half-day offset to the catalog's PEpoch column convention is kept, not corrected.
- **WEB-PP-UPD-01 Update.** Blank keeps the prior value; whitespace only is an error; grammar `parseDelphiFloat` (32 characters, exponent ≤ 2 digits). Edits longer than 32 characters are refused, not truncated (the DFM sets no MaxLength). A Date error stores nothing; a Density error after a good Date keeps it, leaves texts and stale derived texts, keeps Update enabled and opens the box.
- **WEB-PP-UPD-02 Domain.** No exception path: a fixed echo needs `|v| < 1e15`; a zero or non-finite density, a non-finite quotient or a rounded distance that is not a safe integer, and a period with `|p| ≥ 1e15`, show an empty field with an "outside the OpenVireo numeric domain" note. No value is invented.
- **WEB-PP-NUM-01 Numbers.** binary64 in the listing's order; Singles are already `Math.fround` from the codec. Rounding: `roundHalfEven`, a bounded policy consistent with the compiled control-word cell `0x5ae024 = 0x1332` (addendum COMPILED-CW-CELLS). That cell is a mutable global and the runtime word at `0x5691ef` is unknown; no x87, `StrToFloat` or locale parity. Native stores local JD and density as Extended (form+0x448/+0x452); the web keeps binary64 [W]. At JD ≈ 2451545 binary64 spacing is 2⁻³¹ ≈ 4.66e-10 day (≈ 40 µs), below the 1e-8 day shown by the 8-decimal Date, so that precision is not inherently unsupported; formatter rounding at decimal boundaries and runtime CW/x87 equivalence remain unknown (G4, G6).
- **WEB-PP-FMT-01** `formatFixed`, `formatExponent(v, 5, 2)` and the `0x486bc0` port `skyCoordsFieldsFor`; the identity of `0x40cf28` is not asserted; separator `.`.
- **WEB-PP-NAV-01** `MessageBeep` becomes a polite status line ("First/Last record…"); no audio, no box. "Record n of N" is web text.
- **WEB-PP-FIND-01** Draft bound 64 characters (longer edits refused); commit takes the first 12 code points unchanged; literal, case-sensitive substring with a non-empty query. Escape = Cancel; Enter in a field = OK (DFM `Default=True` on OK).
- **WEB-PP-FIND-02** A miss restores the record shown before Find without redisplay (pending edits stay). Authored not-found wording, labelled as such; the recovered literal text (PP-08) is not shown.
- **WEB-PP-FIND-03** env+0x37ce has no web owner; the first-open mode is the explicit web choice 1 (B1950). No compiled default is claimed.
- **WEB-PP-KEY-01** Enter in Date/Density runs Update only while it is enabled; a held Enter does nothing more. [I] In every reachable state Update enabled implies Default true (edits set both, Reset clears both, display only disables), but VCL key delivery is not claimed.
- **WEB-PP-EXIT-01** Only File ▸ Exit closes the window (the native close-box path is unverified). Exit drops the window and Find memory; focus returns to Open.
- **WEB-PP-PRES-01 Presentation.** The window is a non-modal card. The Find dialog and boxes are application-modal: the rest of the route and the App header/toolbar are inert, Tab is trapped, Escape consumes only the topmost surface. They are presented only on the active route, outside a project operation, without a foreign `<dialog>` and without an antenna surface; otherwise they keep their state unpresented and move no focus. An antenna box arriving while Find is open is presented instead; Find returns afterwards with its draft. Focus: Open → window heading; Find → name field (selected); OK hit/Cancel/Escape/miss box → "Find Pulsar..."; update-error box → the failing Date or Density field; Exit → Open. Disabled, hidden or inert targets are never focused.
- **WEB-PP-HELP-01** Help shows authored web help, labelled as not the original Help file; no HLP text is copied (G7).
- **WEB-PP-SAVE-01** Save investigation excludes the catalog, identity, window and local edits (visible note); reload empties them. No storage, IndexedDB, Worker or network.
